# TypeLine

> One line of text, one line of you.（一行原文，一行你的输入）

纯前端中文打字练习 + 键盘全键测试工具。零依赖、零后端、零构建：双击 `index.html` 即可使用。

## 功能特性

### 打字练习

- **逐行配对输入**：文章每一行对应一个独立输入行，焦点始终落在当前行，视线不跳跃。
- **自适应换行**：隐藏镜像容器承载全文自然换行，窗口缩放、断点切换时自动重分行，已输入内容不丢失。
- **输入法（IME）友好**：
  - 候选窗锚定在**当前输入行下方**，水平跟随已提交光标 / 组合中拼音串末端；
  - 组合中的拼音实时预览显示在输入行（橙色 + 下划线），上屏自动清除、不重复计入；
  - composition 全事件链兼容，切换窗口回来不卡组合态。
- **即时逐字反馈**：正确绿 / 错误红 / 下一字符橙；错字只出现在输入行，原文行不错位。
- **1:1 字符列对齐**：等宽字符槽渲染，半角错字不与原文跑位。
- **实时统计**：用时、字/分、准确率；完成后弹窗汇总并支持换一篇 / 再练一次。统计由输入事件标记 + 1s 心跳合并刷新（V2.0 F4）。
- **书库与分类**（V2.0 #33）：首页五分类卡片按需加载——短文 20 篇（150–300 字）、长文 10 篇（1000–1500 字，首屏镜像测量 ≤300ms，增量测量避免重复全量）、程序预存字 32 组（Java/Python/JavaScript/C++ 各 8 组纯单词列表，空格分隔，含大小写与下划线）、英文选段 10 篇（80–150 词）、古诗文名句 20 篇（40–120 字，含自然换行）；分类数据 .js 壳 + 纯 JSON 内容，动态 script 按需注入，保留 file:// 双击直跑；「换一篇」限当前分类随机且避免连抽同篇；首页提供「继续上次」快捷入口（prefs.cat）。

### 键盘测试

- **104 键可视化全键测试**：功能键行、主键盘区、编辑键区、方向键、数字小键盘分区布局。
- 按下即亮、持久标记，实时进度百分比。
- **测试期全键屏蔽**：测试视图内命中测试集的按键一律阻止默认行为（F5 不刷新、F12 不进调试等），顶部导航区保留可达性；系统级组合键（如 Alt+F4）由操作系统保留，页面内已作文案披露。

### 通用体验

- 暗色 / 亮色双主题，偏好本地持久化，默认暗色。
- 响应式布局：768px 断点自动调整字号、行距与内边距。
- 纯前端架构：Vue 3 CDN 全局构建 + 原生 CSS Variables + ES5 风格脚本，`file://` 协议双击可运行。

## 快速开始

1. 克隆或下载本仓库；
2. 双击 `index.html`（或任意静态服务器托管）；
3. 无需安装依赖、无需构建、无需后端。

> 首次打开需联网加载 Vue 3 CDN（主源 unpkg，自动回退 jsdelivr）；加载完成后练习过程完全离线。

## 技术栈

- Vue 3.5（CDN 全局构建，经典 script 引入）
- 原生 CSS Variables / Flex 布局 / ResizeObserver
- localStorage 持久化（主题偏好等）
- 无 npm 依赖、无构建工具链

## 数据持久化

- 唯一介质为浏览器 localStorage，无后端依赖；
- 练习历史：`typeline:records:v1`（JSON 数组、500 条环形上限、键名含 schema 版本号），在完成 / 换文 / 切视图时写入；
- 主题偏好：`tp_theme`（V1 遗留键，保持兼容）；
- 损坏数据自动降级为空，页面不崩溃；
- 键盘测试标记与当前练习进度为会话级状态，不跨会话保存；清除浏览器数据将丢失全部本地数据，跨设备迁移由 V2 导出/导入功能（路线图 F9）承接。
